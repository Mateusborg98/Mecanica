# ADR 0002 - Escalabilidade com HPA

- Status: aceito
- Contexto: a aplicação deve suportar variação de carga no Kubernetes.
- Decisão: utilizar HorizontalPodAutoscaler `autoscaling/v2`, baseado em CPU e memória, entre uma e três réplicas.
- Consequências: o cluster precisa do Metrics Server e cada container deve declarar requests de recursos.
