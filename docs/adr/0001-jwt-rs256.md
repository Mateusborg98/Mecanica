# ADR 0001 - JWT com assinatura RS256

- Status: aceito
- Contexto: a Lambda precisa emitir tokens que serão validados pela aplicação principal.
- Decisão: assinar na Lambda com chave privada RSA e validar na API apenas com a chave pública.
- Consequências: a chave privada permanece isolada; a chave pública pode ser distribuída aos consumidores; rotação de chaves exige atualizar os dois ambientes.
